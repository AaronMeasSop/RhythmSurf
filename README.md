# RhythmSurf

Aaron Siveesna Meas-Sop
Interactivité ludique | 2026
Techniques d'intégration multimédias
Collège Montmorency

## Description
Un jeu de rythme en style platformer et course en 2.5D. Le joueur doit chercher les notes pour jouer les sons et éviter des obstacles.

## Commandes
- A / D : gauche / droite
- Espace : sauter
